# Multishop — правила для Claude

- С владельцем общаться только на русском. Код и идентификаторы — на английском, сообщения коммитов — на русском.
- Перед работой прочитать `docs/CONTINUE.md` (ссылки, состояние, порядок этапов).
- Продакшен-деплой запускает только владелец.
- Секреты (ключи Stripe и другие) — только в дашборд Convex; не в чат и не в репозиторий.
- Коммит — только после зелёных `npm test`, `npm run lint`, `npm run typecheck`; каждую проверку запускать отдельно и читать код выхода (`cmd | tail` прячет ошибку).
- Этап ведётся так: границы с владельцем → спека в `docs/superpowers/specs/` → план в `docs/superpowers/plans/` → исполнение по TDD → одно независимое ревью всей ветки → «Итог выполнения» в плане.
