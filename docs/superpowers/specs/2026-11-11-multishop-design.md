# Multishop — спека

Дата: 2026-11-11. Статус: черновик, ждёт подтверждения владельца.

## Что это

Личный ИИ-помощник для продажи б/у вещей. Владелец фотографирует вещь и отправляет фото
боту в Telegram. Бот сам распознаёт вещь, ищет похожие объявления и цены, предлагает цену
и готовит объявление. Владелец нажимает «Да», и бот выставляет вещь на площадки.
Роль владельца минимальна: фото, при необходимости одна-две подсказки («не работает
кнопка», «торг») и подтверждение.

## Границы (согласованы с владельцем)

| Вопрос | Решение |
|---|---|
| Пользователи | Только владелец. Бот отвечает одному Telegram ID, остальным отказывает. |
| Товары | Б/у вещи по одной: одно объявление = одна вещь. |
| Страна | Украина: гривны, тексты объявлений на украинском. Общение бота с владельцем — на русском. |
| Площадки | OLX.ua и eBay. Vinted — не делаем: открытого API нет, автоматизация запрещена правилами. |
| Публикация | Только после подтверждения владельца кнопкой в Telegram. Без «Да» ничего не уходит на площадку. |
| ИИ | Claude через Anthropic API. Ключ — только в переменных окружения Convex. |
| Интерфейс | Telegram-бот + веб-кабинет (список вещей, статусы, цены, продажи). |

## Сценарий

1. Владелец шлёт боту 1–10 фото вещи, по желанию с подписью.
2. Бот отвечает «Разбираюсь…» и запускает анализ.
3. Claude смотрит фото и определяет: что это, бренд, модель, состояние, видимые дефекты.
   Если по фото не понять что-то важное (модель, объём памяти, размер), бот задаёт один
   короткий вопрос, а не гадает.
4. Бот ищет похожие вещи и цены (см. «Анализ цен») и предлагает цену с обоснованием:
   диапазон, медиана, сколько аналогов нашлось.
5. Бот присылает черновик: название, описание, категория, состояние, цена в гривнах
   (и цена в долларах для eBay), на какие площадки выставить.
   Кнопки: «Выставить», «Изменить цену», «Изменить текст», «Отмена».
6. После «Выставить» бот публикует объявления и присылает ссылки.
7. Позже: бот сообщает о сообщениях покупателей и продаже, предлагает снизить цену,
   если вещь долго не продаётся, и снимает объявление с другой площадки, когда вещь
   продана на одной.

## Архитектура

- **Convex** — весь бэкенд: база, файлы (фото), HTTP-эндпоинт вебхука Telegram,
  actions для вызовов Claude, eBay и OLX, cron для периодических задач.
- **Telegram**: вебхук на `convex/http.ts`. Проверка секретного заголовка
  `X-Telegram-Bot-Api-Secret-Token` и Telegram ID владельца.
  Вебхук только записывает задачу и сразу отвечает 200; долгая работа идёт в action
  через `ctx.scheduler`, иначе Telegram будет повторять запрос.
- **Claude**: `@anthropic-ai/sdk`, модель `claude-opus-5-5`, адаптивное мышление.
  Цикл с инструментами (поиск цен на eBay, на OLX), итог — структурированный вывод
  (`output_config.format`) по схеме черновика. Включён серверный fallback на случай отказа.
- **Веб-кабинет**: Vite + React, вход через Telegram Login Widget (только тот же
  Telegram ID). Хостинг на Vercel.

### Данные (первичный набор)

- `items` — вещь: статус (`analyzing` / `needs_input` / `draft` / `publishing` /
  `listed` / `sold` / `cancelled`), фото, распознанные свойства, черновик, цена.
- `priceResearch` — найденные аналоги: площадка, название, цена, ссылка, дата.
- `listings` — объявление на конкретной площадке: id на площадке, ссылка, статус.
- `marketplaceAccounts` — токены OAuth eBay и OLX (хранятся в Convex, в чат не выводятся).

## Анализ цен

- **eBay**: официальный Browse API — поиск активных объявлений по ключевым словам и
  по фото (`search_by_image`). Данные о проданных вещах (Marketplace Insights) eBay даёт
  не всем — проверить доступ; без него ориентируемся на активные.
- **OLX.ua**: официальный Partner API даёт управлять своими объявлениями, но не искать
  чужие. Как получать цены аналогов на OLX — открытый вопрос этапа 1 (варианты:
  публичная выдача сайта, ручная подсказка владельца). Решить до плана этапа 3.
- Цены из разных площадок и валют приводятся к гривне по курсу НБУ.

## Этапы

1. **Черновик из фото.** Бот принимает фото, Claude распознаёт вещь, Browse API eBay даёт
   аналоги, бот присылает черновик с ценой и кнопками. Публикации ещё нет: по «Выставить»
   бот присылает готовый текст для ручной вставки.
2. **Публикация на eBay.** OAuth владельца, Inventory/Offer API, ссылка на объявление.
3. **OLX.ua.** Регистрация приложения в OLX Partner API, публикация, цены аналогов.
4. **Веб-кабинет.** Список вещей и статусы, правка черновиков, история цен.
5. **После публикации.** Уведомления о сообщениях и продаже, снятие с другой площадки,
   предложения снизить цену.

## Риски и что проверить

- Продажа на eBay из Украины: проверить, что аккаунт владельца может продавать, и как
  считать доставку (международная пересылка дорогая — возможно, eBay только для лёгких и
  дорогих вещей; бот может сам предлагать, куда выставлять).
- OLX Partner API: условия доступа для частного продавца, платность публикаций в
  отдельных категориях.
- Стоимость Claude: оценить на реальных фото в этапе 1 (порядок — центы за вещь).
- Ошибки распознавания: защищены обязательным подтверждением перед публикацией.
