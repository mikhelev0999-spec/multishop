# Multishop — этап 1в «Удобный бот»: план

**Spec:** `docs/superpowers/specs/2026-11-11-multishop-design.md`, «Дополнение 2026-11-12:
удобство бота».

1. **Шов Telegram**: `parse_mode: HTML` по флагу, постоянная клавиатура меню,
   `sendChatAction`, `setMyCommands`. Тесты на тело запросов.
2. **Разбор апдейтов**: команды `/items`, `/stats`, тексты кнопок меню → команды;
   `callback_data` вида `action:itemId[:arg]`, новые действия `open`, `pr` (процент),
   `prc` (своя цена), `sold`, `soldat`, `again`, `unlist`. Тесты.
3. **Тексты** (`convex/lib/draftMessage.ts`, `convex/lib/botTexts.ts`): HTML-черновик с
   экранированием, клавиатуры черновика / цены / выставленной вещи, карточка вещи, список
   «Мои вещи», статистика. Тесты на экранирование и лимит 4096.
4. **Данные**: статус `sold`, поля `soldPriceUah`, `soldAt`, ожидание `sold`.
5. **Логика** (`convex/telegram.ts`): действия по статусам (черновик / выставлена / продана),
   цена кнопками с округлением, продажа, снятие, повтор текста, меню, список, статистика,
   «печатает…» при разборе. Интеграционные тесты.
6. Деплой, `telegram:setWebhook` (заодно меню команд), публикация, ревью, итог.

## Итог выполнения (2026-11-12)

Сделаны шаги 1–6. Результат: 227 тестов, линт, типы проходят. Бот загружен в dev, меню команд
обновлено через `telegram:setWebhook`. Telegram принял HTML-черновик: на живом боте показан
черновик свитера.

Сделано сверх плана:
- В сетевых ошибках Telegram больше нет URL с токеном бота (`fetchQuiet`): раньше он попадал
  в логи Convex.
- Кнопка «↩️ Вернуть в продажу» для проданных и снятых вещей.

Исправлено по независимому ревью:
- Кнопки цены несут итоговую сумму (`pr:<id>:<цена>`), а не процент. Нажатие на старом
  сообщении или повторное нажатие ставит ровно то, что написано на кнопке. После нажатия
  кнопки сообщения убираются. Шаги, которые не меняют цену, не показываются.
- Меню приходит и с «Помощью», и с подсказкой «пришлите фото». Кнопки меню сбрасывают
  ожидание ответа.
- «Печатает…» повторяется каждые 4 с, пока идёт разбор.
- Итог продаж считается в отдельной мутации, поэтому продажа записывается, даже если подсчёт
  упадёт.
- Обрезка текста не режет эмодзи пополам.

Не сделано:
- Кнопка «Открыть» черновика, который ни разу не показался, правит старое сообщение. Случай
  редкий.
- Счётчик черновиков включает брошенные черновики.
