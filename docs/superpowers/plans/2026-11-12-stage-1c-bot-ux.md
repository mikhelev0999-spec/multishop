# Multishop — этап 1в «Удобный бот»: план

**Spec:** `docs/superpowers/specs/2026-11-11-multishop-design.md`, «Дополнение 2026-11-12:
удобство бота».

1. **Шов Telegram**: `parse_mode: HTML` по флагу, постоянная клавиатура меню,
   `sendChatAction`, `setMyCommands`. Тесты на тело запросов.
2. **Разбор апдейтов**: команды `/items`, `/stats`, тексты кнопок меню → команды;
   `callback_data` вида `action:itemId[:arg]`, новые действия `open`, `pr` (процент),
   `prc` (своя цена), `sold`, `soldat`, `again`, `unlist`. Тесты.
3. **Тексты** (`convex/lib/draftMessage.ts`, `convex/lib/botTexts.ts`): HTML-черновик с
   экранированием, клавиатуры черновика / цены / выставленной вещи, карточка вещи, список
   «Мои вещи», статистика. Тесты на экранирование и лимит 4096.
4. **Данные**: статус `sold`, поля `soldPriceUah`, `soldAt`, ожидание `sold`.
5. **Логика** (`convex/telegram.ts`): действия по статусам (черновик / выставлена / продана),
   цена кнопками с округлением, продажа, снятие, повтор текста, меню, список, статистика,
   «печатает…» при разборе. Интеграционные тесты.
6. Деплой, `telegram:setWebhook` (заодно меню команд), публикация, ревью, итог.
